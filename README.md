This is an assignment based on violating and implementing the following 4 coding principals

DRY Code Principal
YAGNI Principal
Clean Code Principal
Document your Code Principal

Implemented Principals File - Ryan Davis

DRY Principal: This principle is followed by ensuring all code has a distinct purpose and there is no code 
that overlaps in function or responsibility

YAGNI Principal: This principle is followed by limiting the functionality of the program to only the functions 
and features to only ones that will be used by the program (The basic 4 functions of a calculator) 

Clean Code Principal: This principal is followed by using meaningful naming schemes and simple functions that
only execute their intended functions

Document your Code Principal: This principal is followed by using self-documenting code/variable and comments to explain any code
that may not be self explanatory.
